# `hydro/` — Hydropower Data Processing and Regional Projections

This folder contains notebooks for processing historical hydropower generation data and exploring its regional aggregation and future implications.

Hydropower is treated distinctly due to its dependence on long term climate changes.

---

## 📌 Purpose

- Clean and structure historical hydropower generation records 
- Map plant-level data to balancing regions or zones
- Explore projections under assumed hydrologic trends or climate stress scenarios

---

## 🗂️ Notebook Descriptions

| Notebook Name                     | Function |
|----------------------------------|----------|
| `01_hydropower_data_clean.ipynb` | Loads raw hydropower output records and aligns time resolution to hourly |
| `02_hydro_regional_aggregate.ipynb` | Aggregates hydropower generation across geographic regions  |
